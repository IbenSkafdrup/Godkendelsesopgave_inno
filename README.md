# Godkendelsesopgave 1

StudieGig er en demo-app til en godkendelsesopgave på kurset "Innovation og ny teknologi" (CBS). Appen viser idéen om en platform, der matcher studerende med korte, fleksible opgaver fra virksomheder på tværs af fagområder (marketing, dataanalyse, IT, admin), så de kan opbygge CV-relevant erfaring i stedet for et almindeligt studiejob. Denne version viser kun studenter-siden af appen.

## Kør appen

```bash
npm install
npx expo login
npx expo start
```

Scan QR-koden med Expo Go (iOS/Android), eller kør i simulator via `i` / `a` i terminalen.
